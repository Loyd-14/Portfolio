# Portfolio
Loyiso Sonti — Personal Portfolio Website
1. Project Description
This project is a personal portfolio website developed by Loyiso Sonti, an Information Technology student specialising in Systems Development at Gauteng City College.
The purpose of this website is to introduce me, showcase my technical skills, display examples of my projects, and provide contact information.
The website uses HTML5, CSS3, and JavaScript. It has a modern black, grey, and white design and is responsive, meaning it can adapt to different screen sizes, including computers, tablets, and mobile phones.
This project was created as part of the Web Development module to demonstrate my understanding of website structure, styling, responsiveness, and JavaScript functionality.

No external JavaScript libraries or CSS frameworks are required for the current version.

8. Deployment
The website is intended to be hosted using GitHub Pages.
To publish the website:
1.	Create a public GitHub repository.
2.	Upload index.html, style.css, script.js, and README.md.
3.	Open the repository's Settings.
4.	Select Pages.
5.	Choose the branch containing your website files, usually main.
6.	Select the root folder if your files are stored in the repository's main directory.
7.	Save the settings and wait for GitHub Pages to publish the website.
8.	Open the generated website link and test that all sections and features work correctly.
The live website link should be added to Section 3 after successful deployment.
